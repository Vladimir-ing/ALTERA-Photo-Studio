# ALTERA — AI Identity Studio

Лендинг и портфолио персональных AI-фотосессий: пять визуальных направлений,
адаптивные галереи и лайтбокс. Без фреймворков и сборки — обычные HTML, CSS и JS,
готовые к публикации на GitHub Pages.

Рабочий адрес: https://vladimir-ing.github.io/ALTERA-Photo-Studio/

## Основные настройки

**`index.html`**
- `<title>` и `<meta name="description">` — название сервиса и описание
- `og:title`, `og:description`, `og:url` — превью для соцсетей
- Логотип в шапке — `ALTERA · AI STUDIO`
- Текст хиро-блока
- Три шага в разделе «Как это работает»
- Контакты в футере: Telegram, WhatsApp, почта (в `href` и в видимом тексте)
- Название и год в нижней строке футера

**`js/gallery-data.js`**
- `title`, `tagline`, `description` каждого раздела
- `accent` — цвет-акцент раздела (заголовок, номер, свечение, пункт меню)

## Как добавить фото

1. Подготовь две оптимизированные версии изображения: `thumb-NN.jpg` для сетки и
   `full-NN.jpg` для лайтбокса.
2. Положи их в нужную папку внутри `assets/img/<стиль>/`.
3. Добавь пути, размеры и осмысленный `alt` в соответствующий раздел
   `js/gallery-data.js`.

Раскладка подстроится сама: раздел с 4+ кадрами рисуется плотной мелкой сеткой,
с 2–3 кадрами — крупными плитками.

## Локальный просмотр

```bash
python -m http.server 8000
```

Дальше — `http://localhost:8000`.

## Публикация на GitHub Pages

Репозиторий уже готов к публикации: в корне лежит `.nojekyll`, сборка не нужна.

1. Создай на github.com **пустой публичный** репозиторий (без README, .gitignore и лицензии).
2. Подключи его и отправь код:

```bash
git remote add origin https://github.com/USERNAME/REPO.git
```

```bash
git push -u origin main
```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch**,
   Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт открывается по адресу `https://USERNAME.github.io/REPO/`.
5. Впиши этот адрес в `og:url` в `index.html` и запушь ещё раз.

Дальше любой `git push` в `main` обновляет сайт автоматически.

## Структура

```
index.html               разметка страницы
css/style.css            стили, палитра и раскладка
js/gallery-data.js       данные галереи — сюда добавляются фото
js/main.js               сборка разделов, меню, лайтбокс, скролл-эффекты
assets/img/<стиль>/      thumb-NN.jpg (сетка) и full-NN.jpg (лайтбокс)
assets/og-cover.jpg      превью для соцсетей
assets/favicon.svg       иконка вкладки
```

## Технические заметки

- Шрифты Unbounded и Manrope подключены с Google Fonts, есть системный запасной стек.
- Изображения грузятся лениво, у всех проставлены `width`/`height` — вёрстка не скачет.
- Анимации отключаются при системной настройке «уменьшить движение».
- Лайтбокс: стрелки, клавиши `←` `→` `Esc`, свайп на мобильных, ловушка фокуса.
- GitHub Pages чувствителен к регистру в путях, Windows — нет. Имена файлов только строчными.
