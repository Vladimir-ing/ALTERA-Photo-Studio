# ALTERA — AI Identity Studio

Лендинг и портфолио персональных AI-фотосессий: пять визуальных направлений,
адаптивные галереи, пакеты, вопросы и лайтбокс. Без фреймворков и сборки —
обычные HTML, CSS и JS, готовые к публикации на GitHub Pages.

Рабочий адрес: https://vladimir-ing.github.io/ALTERA-Photo-Studio/

## Что править в первую очередь

**`js/gallery-data.js`** — почти весь текст и все цифры сайта лежат здесь:

| Что | Где |
|---|---|
| Разделы галереи: `title`, `short`, `tagline`, `description`, `accent` | `GALLERY` |
| Цены, сроки и состав пакетов | `PACKAGES` |
| Telegram, WhatsApp и текст первого сообщения | `CONTACT` |
| Блок «исходник → результат» | `COMPARE` |

`short` — короткое имя стиля: оно идёт в меню и в подписи превью, где полное
название не помещается. `accent` — цвет раздела: он подхватывается заголовком,
номером, свечением и пунктом меню автоматически.

**`index.html`**
- `<title>` и `<meta name="description">`
- `og:title`, `og:description`, `og:url` — превью для соцсетей
- Текст хиро-блока и три шага в разделе «Как это работает»
- **Вопросы и ответы** — секция `#faq`, прямо в разметке
- Контакты в футере

## Цены

В `PACKAGES` пока стоят заглушки `0 000 ₽` и `0–0 дня`. Пока в цене есть нули,
над блоком на сайте висит оранжевая плашка «Черновик» — она пропадёт сама,
как только появятся настоящие цифры. Больше нигде цены менять не нужно.

## Блок «исходник → результат»

Самый убедительный блок на странице: человек видит, что из обычного снимка
с телефона получается кадр из галереи. Сейчас выключен — `COMPARE = null`,
раздел просто не рендерится.

Чтобы включить:

1. положи исходное фото в `assets/img/source/`;
2. заполни объект `COMPARE` по образцу в комментарии рядом с ним;
3. укажи, какой кадр галереи из этого исходника сделан.

## Как добавить фото

1. Подготовь две версии: `thumb-NN.jpg` для сетки и `full-NN.jpg` для лайтбокса.
2. Положи их в `assets/img/<стиль>/`.
3. Добавь пути, размеры и осмысленный `alt` в нужный раздел `js/gallery-data.js`.
4. Сделай WebP-версии — они грузятся вместо JPEG и весят вдвое меньше:

```bash
python3 -c "
from PIL import Image; import glob, os
for f in glob.glob('assets/img/*/*.jpg'):
    w = os.path.splitext(f)[0] + '.webp'
    if not os.path.exists(w):
        Image.open(f).convert('RGB').save(w, 'WEBP', quality=82, method=6)
"
```

JPEG остаётся запасным вариантом: разметка отдаёт оба через `<picture>`,
браузер выбирает сам. Если WebP-версии нет, страница не сломается — просто
загрузится JPEG.

Раскладка подстроится сама: раздел с 4+ кадрами рисуется плотной сеткой,
с 2–3 кадрами — крупными плитками.

## Логотип

`assets/logo/altera-mark.svg` — фирменный знак: октаэдр с «А» в центре.
Треугольник не залит цветом, а вырезан маской, поэтому сквозь него видно фон
и знак одинаково работает на тёмном полотне и на плашке.

Знак используется в шапке, крупным водяным знаком в хиро и на заставке.
`assets/favicon.svg` — упрощённая версия для мелких размеров: в 16 px блик
и контрформа «А» превращаются в грязь, поэтому там их нет.

Если правишь знак, пересобери и растровые иконки — `apple-touch-icon.png` (180),
`icon-192.png` и `icon-512.png`. Они делаются из `assets/favicon.svg` любым
конвертером SVG → PNG, но **без скруглений**: iOS и Android накладывают свою
маску, и вторые скруглённые углы дают заметную кайму.

## Локальный просмотр

```bash
python -m http.server 8000
```

Дальше — `http://localhost:8000`.

## Публикация на GitHub Pages

Репозиторий уже готов к публикации: в корне лежит `.nojekyll`, сборка не нужна.
**Settings → Pages → Source: Deploy from a branch**, Branch: `main`,
папка `/ (root)`. Дальше любой `git push` в `main` обновляет сайт автоматически.

## Структура

```
index.html               разметка страницы
css/style.css            стили, палитра и раскладка
js/gallery-data.js       все тексты, цены и фото — правится в первую очередь
js/main.js               сборка разделов, меню, лайтбокс, скролл-эффекты
assets/img/<стиль>/      thumb-NN (сетка) и full-NN (лайтбокс), JPEG + WebP
assets/logo/             фирменный знак
assets/og-cover.jpg      превью для соцсетей (только JPEG: WebP соцсети не читают)
assets/favicon.svg       иконка вкладки
site.webmanifest         имя и иконки при сохранении на домашний экран
```

## Технические заметки

- Шрифты Unbounded и Manrope подключены с Google Fonts, есть системный запасной стек.
- Изображения грузятся лениво, у всех проставлены `width`/`height` — вёрстка не скачет.
- Анимации отключаются при системной настройке «уменьшить движение».
- Галереи, пакеты и меню собираются скриптом из `gallery-data.js` — при
  отключённом JS их не будет. Намеренно оставлены в разметке и работают без
  скрипта самые важные для поиска части: хиро, «Как это работает», вопросы
  и контакты.
- Разметка `FAQPage` собирается из тех же элементов, что видит пользователь,
  поэтому текст в поисковой выдаче не может разойтись с текстом на странице.
- Заставка показывается один раз за сессию и снимает себя по таймауту:
  даже если `main.js` упадёт, страница не останется закрытой.
- Прокрутка при открытом меню и лайтбоксе блокируется фиксацией `body`
  с возвратом позиции. `overflow: hidden` для этого не годится: он не
  останавливает прокрутку, зато ломает `sticky`-шапку.
- Размытие шапки живёт на псевдоэлементе. `backdrop-filter` на самой шапке
  создаёт containing block для `position: fixed`, и мобильное меню уезжало
  за экран вместе с ней.
- Лайтбокс: стрелки, клавиши `←` `→` `Esc`, свайп на мобильных, ловушка фокуса.
- GitHub Pages чувствителен к регистру в путях, Windows — нет. Имена файлов только строчными.
